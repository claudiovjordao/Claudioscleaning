# Claudio's Cleaning Website

This is a lightweight static website designed to run for free on Cloudflare Pages.

## Files
- `index.html` — website content
- `styles.css` — design and mobile layout
- `script.js` — mobile menu and current year

## Publish on Cloudflare Pages

1. Create a free Cloudflare account.
2. Go to **Workers & Pages** → **Create** → **Pages**.
3. Connect this GitHub repository.
4. Use the `main` branch.
5. No build command is required.
6. After the site is live, open the project's **Custom domains** section.
7. Add `claudioscleaning.com`.
8. Keep Zoho's MX records in DNS so email continues working.
